# WriterToolkit

Набор личных инструментов для писателей и редакторов, созданный для повышения продуктивности при работе с текстом.

## Возможности

- редактор нескольких документов со сценами и альтернативными вариантами;
- drag-and-drop сцен мышью, касанием и клавиатурой, плюс доступные кнопки перемещения;
- автосохранение в IndexedDB, Undo/Redo, поиск по всем вариантам и настройка шрифта;
- атомарное удаление документов с десятью локальными recovery-копиями;
- импорт и экспорт JSON без потери текстовой проекции;
- аудит текста: счётчики символов по категориям, подсветка категорий и писательских артефактов (смешанные скрипты, двойные пробелы, невидимые символы, повторы, слова-паразиты), поиск по подстроке и регулярке;
- пословное и построчное сравнение двух редакций;
- GFM Markdown-превью с корректными списками и санитизацией HTML;
- безопасное преобразование обычного текста в HTML;
- локальные черновики вторичных инструментов.

Тестер клавиатуры и лемматизатор намеренно удалены. Недоработанные кастомные таблицы не входят в v1.

## Требования и запуск

- Node.js 22.22 или новее; рекомендуемая версия закреплена в `.node-version` и `.nvmrc`;
- npm из поставки Node.

```bash
npm ci
npm run dev
```

Полная локальная проверка:

```bash
npm run check
npx playwright install chromium
npm run test:e2e
```

Production-сборка и Pages-like preview:

```bash
npm run build
npm run preview:pages
```

Preview доступен по `http://127.0.0.1:4173/WriterToolkit/`. Сервер имитирует GitHub Pages и отдаёт `404.html` для вложенных SPA-маршрутов.

## Данные и совместимость

Пользовательские тексты не отправляются на сервер. Документы, recovery-копии и черновики остаются в IndexedDB текущего browser profile; размер шрифта редактора хранится как небольшая preference.

Legacy JSON импортируется в новый документ только после полной проверки. Перегенерация технических ID допустима, но сохраняются:

- порядок и названия сцен;
- порядок и точный текст каждого варианта;
- позиция активного варианта;
- пустые строки, пробелы, Unicode и переносы внутри текста.

Round-trip проверен на локальных `example.json`, `chapter19.json` и `schoons.json` из замороженной версии. `old_frozen/` и приватные fixtures исключены из Git и production artifact.

## GitHub Pages

Workflow в `.github/workflows/deploy.yml` запускает format/lint/typecheck/unit/build/E2E, затем публикует только `dist/` из `main`. Vite base закреплён как `/WriterToolkit/`; build создаёт `404.html`, поэтому прямые чистые URL открываются без hash routing.

В настройках репозитория Pages следует выбрать GitHub Actions как source.
